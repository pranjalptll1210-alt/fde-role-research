# Forward deployed engineering

**Build software with customers, then make it work in their environment.**

Across this sample, FDEs clarify an operational problem, integrate data and systems, ship a solution, and feed lessons back into the product. The mix ranges from data applications to production AI. This is a synthesis of [five employer postings](./sources), not a universal job definition.

## What the work involves

| Work | What you actually do | Evidence |
| --- | --- | --- |
| Understand the problem | Work with users and decision makers; clarify the workflow and constraints. | [Palantir new grad](./jobs#palantir-new-grad), [Anthropic](./jobs#anthropic) |
| Build and integrate | Write applications, connect data and APIs, resolve deployment blockers. | [Google Singapore](./jobs#google-singapore), [Palantir intern](./jobs#palantir-intern) |
| Deliver in production | Move beyond a prototype; support reliability and adoption. | [Google London](./jobs#google-london), [Anthropic](./jobs#anthropic) |
| Improve the product | Turn recurring customer problems into reusable patterns and product feedback. | [Google Singapore](./jobs#google-singapore), [Anthropic](./jobs#anthropic) |

## What changes by career stage

- **Internship:** practical coding evidence and student eligibility. Some AI internships already ask for production experience.
- **New graduate:** programming fundamentals plus ownership of customer projects; a specific graduation window can be mandatory.
- **Experienced:** production delivery, customer discovery and deeper AI experience. Do not treat these as entry-level roles.

Travel and office expectations matter: both sampled Palantir roles discuss 25–50% travel; Anthropic also lists 25–50%. See each [job’s constraints](./jobs).

## Where to focus

Start with **programming → data/API integration → deployment → customer communication**. Add agents, retrieval and evaluation when targeting AI-heavy roles. The [skills page](./skills) separates employer requirements from suggested portfolio evidence.

**Scope:** 3 internships + 2 full-time roles, across 3 employers and 4 locations. A small purposive sample, not a ranking or a market-wide survey. [Read the method](./sources).
