# Skills to build

**A preparation guide, not a universal hiring checklist.** Follow the requirements of the specific role. Evidence below links to the summarized posting and its original source.

## AI-specific skills

- **Retrieval and data readiness:** vector databases and RAG are explicit in [Google London’s minimums](./jobs#google-london).
- **Agents and orchestration:** preferred at [Google Singapore](./jobs#google-singapore); production agent experience appears in [Anthropic’s profile](./jobs#anthropic).
- **Evaluation and observability:** Anthropic names evaluation frameworks; Google names token throughput, request cost, state management and tracing. [Sources](./jobs)

Do not assume every FDE role requires every agent framework. Google lists LangGraph, CrewAI and ADK as examples, not a requirement to master all three.

## One focused portfolio project

*Suggested preparation, inferred from the work above; not an employer requirement.*

Build a tool for one real operational workflow: interview a user, ingest imperfect data, integrate an API, deploy a usable interface and measure whether it helps. If AI is justified, add a small evaluation set plus latency/cost tracking. Include a short handoff document so someone else can run it.

For an internship, emphasize what you personally implemented and learned. For full-time roles, explain production reliability, customer constraints and the decisions you owned.
